# Flight Center · Sistema de reservas (demo)

Versión demo del sistema de reservas de la escuela de vuelo Flight Center.
Todo funciona dentro del navegador: los datos se guardan en el navegador de cada persona.

Cuentas de prueba (contraseña `flight123`): alumno@flightcenter.com, ppa@flightcenter.com,
instructor@flightcenter.com, mecanico@flightcenter.com, admin@flightcenter.com.

Se publica con GitHub Pages desde la rama `main` (carpeta raíz).
